# NARA KITCHEN — ORDERIN V1 Demo

ORDERIN V1 sekarang dikemas sebagai demo restoran fiktif **NARA KITCHEN, Cirebon**.

## Yang sudah tersedia
- Landing page restoran
- Story / cerita brand
- Promo
- Menu dengan 5 kategori: Nasi, Mie, Snack, Minuman, Dessert
- 12 menu contoh dengan harga dan deskripsi
- Best seller
- Search & kategori
- Detail menu + pilihan varian
- Keranjang
- Checkout
- Generate order ke WhatsApp
- Nomor order
- Admin dashboard
- Kelola produk
- Status pesanan
- Pengaturan bisnis
- Data disimpan di localStorage

## Data demo restoran
- Nama: NARA KITCHEN
- Lokasi: Cirebon, Jawa Barat
- Alamat demo: Jl. Tuparev No. 88, Cirebon
- Jam: 10.00–22.00
- Promo: Gratis Es Teh untuk minimal pembelian Rp75.000

## Cara menjalankan
1. Extract ZIP.
2. Buka `index.html`.
3. Admin: `admin/index.html`.

## Catatan
NARA KITCHEN adalah brand demo/fiktif untuk showcase. Nomor WhatsApp dan alamat adalah data contoh.
Foto makanan asli dari Google Maps belum dimasukkan. Untuk versi publik/komersial, gunakan foto milik sendiri atau aset dengan lisensi yang mengizinkan penggunaan tersebut.

## Tahap berikutnya
Setelah struktur ini cocok, visual bisa dirombak dengan Google Stitch menjadi UI restoran premium tanpa mengubah alur ORDERIN.
